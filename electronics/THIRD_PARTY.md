# Component and CAD library attribution

Local stock KiCad symbols and footprints originate from the KiCad libraries:
- https://gitlab.com/kicad/libraries/kicad-symbols
- https://gitlab.com/kicad/libraries/kicad-footprints

KiCad library content uses CC BY-SA 4.0 with the KiCad Libraries Exception: https://www.kicad.org/libraries/license/ . Local library identifiers and existing attribution are retained. Project-level hardware licensing does not overwrite the library license or exception.

Custom package outlines implement dimensions from manufacturer drawings. The BOM, pin map and docs/electronics.md identify selected parts and primary datasheets. Manufacturer names identify components, not endorsement or certification. Vendor PDFs/HTML snapshots are no longer redistributed: reference-sources.json preserves their original hashes and source links.

Firmware SDK/runtime notices are in ../firmware/THIRD_PARTY_NOTICES.md. No production credentials or private manufacturer application are provided.
